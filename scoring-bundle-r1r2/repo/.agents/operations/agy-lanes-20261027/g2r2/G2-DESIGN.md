# G2 design (g2r2, 2026-10-27). CPU only, one Slurm array task per executable arm, family runner unchanged.
**What G2 needs.** No GPU: every family inference runner asserts `SLURM_JOB_PARTITION=='cpu'` and runs the predictor with device cpu (GPU was only for the H1/H3 refits, finished). cpu nodes: 256 CPUs, 2 TB, 24 h limit, idle. Inputs are whole exported tensors resident in memory, so size memory per family from the manifest export bytes (stat only); suggest 16 cpus / 128 GB / 12 h until measured (unmeasured: no per-role timing exists; R1 `forward_seconds` in commitments is the only reference).
**Pieces (all tested on synthetic fixtures, none run on real data).**
1. `g2/stage_source.py`: stages the pinned source root from the pre-amendment commit (`6bebfc7c^`), because all 8 family pins.json still pin the OLD forecast_recipes.py (verified: the working tree fails every family pin check; see AMENDMENT-IMPACT.md). Writes `scientific-closure.json`. Closure paths must be the final cluster path: stage with `--final-root`, then `tar | ssh <BATCH_HOST> tar -x`.
2. `g2/g2_exec.py`: in-job executor for one arm. Fills only live-allocation facts (job id, cpus, mem), the runtime-evidence doc (numpy/polars/torch files only; interpreter stays bound as `python`, it exceeds 16 MiB), the resource-admission doc (repeats template `history_bounds`/`sources`), creates spec `output_parents` dirs and an approval derived from root's `ROOT-GO-G2.txt`; then calls the family's `run(plan_ref, approval_ref)`. All science checks stay in the runner (frozen arm vs plan, custody hashes, fit provenance, label-free inputs, schema, `verify_arm`). No retry: records dir and outputs are exclusive, failure goes to `failure-N.json`.
3. `g2/g2_submit.py`: writes the array script (`env -i`, `python -I -B`, thread counts = cpus) and prints/runs `sbatch --export=NIL --partition=cpu --no-requeue --array=0-N%C` with real -o/-e files.
4. Test: `g2/test_g2_exec.py` runs the unchanged ordinary runner (real GBDT fit + inference + verify_arm) through steps 1-2 on the family fixture: passes; retry refused.
