# Bounded outcome capture and terminal waiter

The capture CLI has one fixed root, the prospective current-day-equivalence-rv3-20250314-v1/attempt. It reads only intent.json, result.json, failed.json and each of 96 exact archive-NNN/{result,failed}.json paths. Missing files remain missing and never imply success or terminal status. Canonical regular files only, 1 MiB each and 8 MiB total; output at most 4 MiB. Export uses typed allowlisted metadata: source/approval bindings, file hashes, exact equality/multiplicity counts, archive filename/content bounds, and bounded references. It never follows receipt references or reads MRT, Parquet, logs or error payloads. Failure reason text stays in custody; only its hash and length leave, alongside the exception type.

The aggregate committed component must be the exact fd18cdfc object, and source-equivalence-only/no-admission flags are preserved. Capture is evidence transport, not independent numerical verification or N admission. It can be run once after actual scheduler termination; root supplies the reviewed source bytes to remote Python through stdin and retains stdout/stderr locally. No new remote source staging is required. A separate scoped diagnostic is needed if terminal failure precedes any metadata receipt; this capture must not broaden itself to arbitrary logs.

The waiter follows the existing project pattern: bounded read-only sacct queries for one actual decimal job ID on <SUBMIT_HOST>, then an existing <AGENT_TOOL> owner-pane wake after verifying Codex/current directory/session. Exact top-level job state is required; batch steps, missing/duplicate scheduler rows and nonzero query exits do not imply termination. One exclusive send-intent precedes the wake; no automatic resend after uncertainty. At most 300 polls, 30-second intervals, each query at most 30 seconds, plus bounded owner notification. It never captures scientific content, launches work or retries the job. The root must supply actual job/pane/session bindings after submission; the draft request intentionally lacks them.

25 local synthetic tests passed. They cover equality and inequality, exact receipt hashes, redacted reasons, payload omission, exact intent/committed identity, canonical paths/symlinks, size/aggregate bounds, malformed metadata, exact scheduler rows and single correctly bound wake. No remote calls or actual outcomes were read.
