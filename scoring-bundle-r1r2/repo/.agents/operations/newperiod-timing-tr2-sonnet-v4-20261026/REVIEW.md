# T-R2 v4 (sonnet) — probe v2 after the consumed v3 probe refused TR2P_R_IMPORT

v3 is untouched, including its consumed `actual-probe/attempt1` (STOPPED, no retry). v4 carries everything else from v3 PASS (request, projection operator, gate stage, typed provenance, probe acceptance/ancestry/admission) and changes only the probe hook/limits, its scope/namespace and the pins that follow. Nothing issued/run by root. `tests-regression-first.txt` = the 57 new v4 tests failing against the v3 probe module; `tests.txt`/`verification.json` = 149 tests pass.

## Cause (confirmed from the stack on the cluster, replica runs below)
`torch` -> `cuda.bindings` -> `cuda/pathfinder/_dynamic_libs/load_dl_linux.py` -> `ctypes.util.find_library('dl')` -> `_findSoname_ldconfig`: `subprocess.Popen(['/sbin/ldconfig','-p'], stdin/stderr=DEVNULL)`; DEVNULL = `os.open('/dev/null', O_RDWR)`. The v3 hook refused that write-open, `Popen` raised `PermissionError` (an `OSError`, which `find_library` swallows) and it fell back to `_findLib_gcc` -> `tempfile.NamedTemporaryFile` (`open('/tmp','w+')`, then a linked `/tmp/tmpXXXX` file). Independently, `tempfile.gettempdir()` creates files to probe /tmp, which FSIZE 0 / the write-deny breaks. The fallback is only reached when the ldconfig path is refused: with `/dev/null` and the exact ldconfig call allowed, no temp file is ever opened (run-04).

## Probe v2 hook (`tr2_import_probe_operator.py: HOOK_SOURCE`, single source for probe, replica and tests)
Allowed exactly: write-open of `/dev/null` without O_CREAT/O_TRUNC/O_APPEND; anonymous `O_TMPFILE` open of `/tmp` only, requiring O_EXCL (never linkable) and no O_CREAT (requested allowance; run-04 shows the import does not need it); `subprocess.Popen` of exactly `/sbin/ldconfig` with argv `['/sbin/ldconfig','-p']` (list/tuple, no shell: a shell run is executable `/bin/sh` and refused), cwd None, env None or LC_ALL=C. `ctypes.dlopen` is deliberately NOT denied (run-07).
