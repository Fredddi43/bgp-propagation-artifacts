2. **Budget reservation, not the reviewed Budget class**: `reviewed_budget.py` byte-identical (pinned). Only the value passed in changes: `output_total_bytes` 640 MiB -> 2 GiB. Runner check relaxed from `write_bytes == output_total_bytes` to `write_bytes + file_bytes <= output_total_bytes` (640+512 = 1152 MiB <= 2048 MiB), so the kernel bound always trips first and Budget can never refuse a legal write. `free_floor_bytes` check relaxed `==` to `<=`: plan floor (v43, 795.6 GB) <= resource floor (V44 minimum 847.6 GB), i.e. the runner disk admission uses the CURRENT phase floor; kernel Writes keeps the weaker v43 floor in-job (4 shards x <= 640 MiB cannot cross the 52 GB gap).
