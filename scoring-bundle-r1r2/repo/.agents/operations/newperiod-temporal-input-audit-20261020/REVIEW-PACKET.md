## What this implements

`producer.py` supplies a production-capable guarded writer for two N temporal stream/resource audits. Before any output or tensor decode, it requires exact independent audit execution approval and both current N development seals, invokes the real `forecast_release.authorize(core_fit)` and development validator, checks source/incident/construction/failure evidence, fixed recipe panel/calendar and exact tensor hashes. A `core_fit` seal is used as the existing development access boundary; the additional separate audit approval authorizes **only supervised-container decoding and input-audit writing**, never a fit or label-value analysis. It does not create a new scientific operation or broaden a seal.

Both horizons are checked before output creation. One exclusive output root and `started.json` preserve a single attempt; an existing/partial/failed root refuses. Audits run sequentially. Success writes a final completion binding both receipts; any caught failure preserves `failed.json`; abrupt failure retains the exclusive root and is never retried automatically. Partial d30 output is not a successful two-horizon completion. Original seals, manifests, inputs and source evidence remain immutable.

`original_temporal_input_audit.py` is copied byte-for-byte from the audited retrospective producer. The new producer calls its unchanged `rebuild_message_counts` helper. It preserves the original whole-second count equality, train/validation capacity check, training-only tie statistics, max-usable-messages/event-ID resource-input choice, sample-variance normalization and output shape. It replaces the retrospective validator with the reviewed N guards and adds the generic `forecast_inputs.validate_tensor(... input_profile='temporal')` validation plus exact development construction/history checks. Scientific source remains the original 76-file temporal map with only the four previously reviewed N guard differences.

Tensor bytes are read once, SHA256-checked against both sealed input map and manifest **before** deserialization, and projected to the allow-listed temporal inputs. Label fields necessarily exist in supervised serialized containers, but their values are not inspected, validated, selected, normalized, summarized or written. Approval must explicitly acknowledge supervised-container decoding; `label_values_authorized` remains false. Source and incident evidence, and both development manifests, must pass before this boundary. The producer cannot decode test partitions or dispatch an exporter, model, optimizer, predictor or scorer.

The input-only projection validates finite features and messages, message shape/endpoints/integer indices, nonnegative and horizon-bounded timestamps, collector panel, identity, feature/history contracts and availability. Message counts must equal the independently reconstructed rule-A stream. Validation inputs contribute only capacity and stream checks; validation feature values and all label values cannot influence normalization. Excluded input rows and their verified evidence are preserved verbatim; missing files, missing training inputs or missing rebuild coverage refuse rather than become zeros. The producer does not alter any declared target censoring state or turn missing target coverage into an empty target.
