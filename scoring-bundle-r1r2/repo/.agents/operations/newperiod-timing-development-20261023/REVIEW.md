Persistence and the original mean/k20 history prediction and membership metric functions run unchanged on original matched candidates. Historical queries use causal snapshots at each validation issue time. Original library sources can contain later events, but later labels never enter those snapshots or choose a configuration. It writes the readiness schema the timing client already requires. Score magnitudes do not affect this decision. The actual results still require independent review before fit release.
