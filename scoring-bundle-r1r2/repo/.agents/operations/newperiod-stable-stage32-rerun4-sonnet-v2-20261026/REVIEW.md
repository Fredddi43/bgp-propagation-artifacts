### Budget justification (finding 4)
Observed 13/15 refusal is `Budget.reserve` (`reviewed_budget.py:24`: `used+per_file>total`), per_file 512 MiB reserved ahead of each write. The reservation is only a precondition; the real data bound is kernel `Writes` 640 MiB. The least total that never refuses a kernel-legal write is therefore `write_bytes + file_bytes = 1152 MiB` (exactly what the test shows).
