# Pooled selector compatibility — local candidate

The actual N manifests contain `reference_collectors: "pooled"`; their frozen recipes describe an explicit ten-collector acquisition inventory. Old source-audit, temporal and GBDT preflights compared those different concepts literally and refused the valid selector.

This candidate preserves the selector, original scientific modules, recipes, fit counts, resource contracts, calibration/release and failure policies. It adds an exact `collector_inventory` metadata prerequisite to the prospective temporal/GBDT packages and standalone source-audit schema. The inventory must bind the frozen recipe, correct arm, both actual manifest references, core-gate-bound source audit and source-audit-bound staging receipt. It is never inferred from successful rows. Source/staging status and root digest must match. These checks establish acquisition identity, not complete archive coverage or permission to fit.

`source_guard.py` is the small shared overlay root integrates into its separately reviewed Chronos/development-count wrappers. Its API is `preflight(..., collector_inventory=None, recipe_arm='N-temporal')`. `collector_inventory.py` is the exact independently reviewed helper109c2a86. Pooled input frame selection and all numerical/source-comparison functions are unchanged. Standalone source-audit approval accepts truthful Codex identity from a separate worker/session; it does not self-approve. This directory does not assemble a standalone source-audit execution package or protected-export package.

The two prospective client directories contain complete local code/template closures. `bound_selector.py` combines the exact helper with the core-gate/source/staging binding adapter. The runners compile its exact already-hashed bytes, so `-I` works without trusting import caches or ambient search paths. All original scientific and guard snapshots are preserved byte-for-byte. The existing GBDT historical `adapter-code-review.txt` is preserved as predecessor evidence only; it does not approve this amendment. Actual new operation/execution reviews remain mandatory and unresolved.

Reproduction: `python3 build_guard.py`; `python3 build_clients.py`. Builders modify only this candidate directory. Validation: `.venv/bin/python -B -m pytest -q .agents/operations/newperiod-selector-compat-20261023/test_selector.py` (25 passed); `.venv/bin/python -B .agents/operations/newperiod-selector-compat-20261023/run_inherited.py` (124 passed). No SSH, Slurm or scientific data/labels/fits were accessed. Only already-approved local source/staging metadata was inspected to confirm its real status/root/staging schema matches the new adapter.
