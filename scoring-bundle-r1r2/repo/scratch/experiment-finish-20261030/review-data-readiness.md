## Blocking findings

A split document must be verified through its declared representation, never treated as optional.

2. **P1 — The durable completion verdict and artifact graph are not checked.** `audit/validate_final_data.py:215-251` checks four filenames and selected self-reported header fields but never reads `completion.json`, verifies either primary equality flag, validates the approval-to-ready hash chain, or checks preparation byte bindings. A fixture with `completion.passed=false`, nonempty blocking, false primary equality, nine duplicate `counts` header entries carrying `persist_error`, wrong document kind, empty family science, and no raw aggregate passes every Tier C check even with `--deep`. Require both primary canonical equalities with only the two original allowed exclusions, and bind each family manifest to its unique header entry. Validate intent, D-A39 marker, immutable original marker/primary/score references, approval, the exact approved ready record/code, and stage bindings. Presence of a historical ready filename at lines168-170 is not this proof. The successor author's durable completion record is defined in `author/chain/r2_rescore_secondary.py:784-797`; its header gate is preliminary and cannot describe a later result-write failure.

3. **P1 — Header parsing fails for valid large JSON; split output is not implemented.** `audit/validate_final_data.py:204-207` decodes a complete top-level JSON value from only its first 8 MiB. JSON sorting puts the header first but does not terminate the enclosing document there. A valid 9 MiB document raises `JSONDecodeError`. Decode the header value itself with an appropriately bounded streaming parser, then verify the entire document through its durable receipt. Handle the driver's `secondary_result.split` manifest and every concatenated part as the alternate JSON representation. Original `r2_rescore_secondary.py:269-306,634-635` writes encoded JSON **as raw bytes**, manifest `format='raw-bytes'`; it does not pickle those JSON bytes. The report's description of this fallback as bytes pickled in parts is inaccurate.

4. **P1 — Science coverage is never validated.** `audit/validate_final_data.py:219-251` verifies nine filenames and selected headers, but never verifies result composition or the retained identity union. 5. **P1 — The receipt-proof implementation does not preserve D-A26's no-symlink or digest guarantees.** `audit/validate_final_data.py:131-132` inserts the template's claimed digest directly into `SELF_HASHED` without hashing the template; Tier B then accepts that claim at lines183-188. ## Final-state false positive
