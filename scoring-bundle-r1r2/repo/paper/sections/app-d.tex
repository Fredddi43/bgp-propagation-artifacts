\section{Ethics}\label{sec:ethics}
This work does not involve human subjects or user traffic.
It uses public BGP archives (RIPE RIS, RouteViews, PCH) and public RPKI ROA archives.
It also uses public event catalogues (Cloudflare Radar, GRIP) and published per-AS ROV measurements (RoVista).
Further sources are CAIDA datasets and the BGPKIT peer statistics, which we used to choose the collectors.
All data of this study come from these passive sources.
% src (round 4, panel-r4 P5 / T3): BGPKIT peer statistics of 2024-06-15 select the ten collectors (sections/03-data.tex, refs.bib bgpkit).
The authors made no BGP announcements and sent no active probes.
% src: no announcement, beacon or probe tooling or data by the authors exists in the repository (docs/plan/gap-register.md names RIPE Atlas and Ark as options only). Confirmed true by the authors on 2026-10-31.

The paper names some networks, for example upstreams that stopped carrying an RPKI beacon (\Cref{sec:beacons}).
Such a name reports what our collectors observed, not a judgement of the filtering policy of that network.
The paper does not assign intent to any network.

An observed origin change or an invalid origin is not evidence of an attack.
For this reason the paper calls the first transition of a recovery pair the outward change.
Some file names of the released recovery tables still use the word hijack, which follows the catalogue label and claims no attack.
The released artifact keeps public prefixes, AS numbers and collector names, because they define the measurements.
% src: scratch/release-public-final-20261016/MANIFEST.json (31 paths named *_hijack_first_transition); sections/06-recovery.tex (outward transition).

A forecast of which ASes an event will reach could help an attacker to choose a leak or hijack with a wide reach.
We judge the added risk low, because the forecasts add little over a history baseline that anyone can build from public data (\Cref{sec:forecast}).
A hijacker can already try to keep a route away from collector peers~\cite{milolidakis2023}.
Past public events show which ASes recur on collector-visible paths, so our forecasts add little to such an attempt.
% round-3 reviews M11 / second reviewer W6: dual use argued from low marginal value, and collector evasion named (milolidakis2023, cited in sec:back).
The study found no software vulnerability, so no disclosure was needed.
% src: no vulnerability record exists in the repository either way; confirmed true by the authors on 2026-10-31.

\section{Open Science}\label{sec:openscience}
We release code and derived data in an anonymous repository (\url{https://anonymous.4open.science/r/bgp-propagation-artifacts-BE40/}).
A permanent archive link replaces it in the final version.
The package holds the replay code and the event identifiers with the observed path-AS sets for January 2022 to August 2026.
It flags unavailable source windows and unsupported withdrawal baselines.
It also holds the RPKI validity tables, the recovery pairs, the beacon measurements, and the retained checkpoints and per-event evaluation tables of the slow-regime experiments.
It gives instructions to reproduce the main tables and figures with Python 3.12.

\section{Generative AI}\label{sec:genai}
Generative AI tools helped with this work, under the direction of the authors.
\emph{Writing.} The tools drafted and revised text in all sections, including the abstract, the captions and the appendices.
The authors edited and approved the text of the paper.
\emph{Code.} The tools wrote and changed code for data intake, replay, RPKI validation, measurement, model training and evaluation.
They also wrote and changed the code for tables and figures, and the scripts that run compute jobs.
